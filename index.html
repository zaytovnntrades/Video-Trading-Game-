Set up your session

You start with $10,000 of fake money. The chart plays forward one candle at a time. You can go long (buy), go short (sell) and close, with an optional stop-loss and take-profit.

Shortcuts: Space = play/pause · N = next candle · B = buy/long · S = sell/short · C = close position
